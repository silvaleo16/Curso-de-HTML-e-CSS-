# 📚 Repositório de Estudos em HTML, CSS e JavaScript

Este repositório reúne uma coleção de projetos desenvolvidos com o objetivo de praticar e aprimorar conhecimentos em **HTML**, **CSS** e **JavaScript**. 
Cada projeto representa uma etapa do aprendizado, abordando desde conceitos básicos até funcionalidades mais avançadas do desenvolvimento web.

## 🎯 Objetivos

- Praticar a estruturação de páginas com HTML.
- Aprimorar a estilização utilizando CSS.
- Desenvolver interatividade com JavaScript.
- Consolidar conceitos fundamentais do desenvolvimento Front-end.
- Criar um portfólio de projetos para acompanhar a evolução dos estudos.

## 🛠️ Tecnologias Utilizadas

- **HTML** – Estrutura das páginas.
- **CSS** – Estilização, responsividade e animações.
- **JavaScript** – Lógica, manipulação do DOM e interatividade.
